# XMP 更新

按表格修改 XMP sidecar 里的标签。有两种方式：

- **按 xmp_update 列修改**：在表的 `xmp_update` 列填新值（时间填 `xmp_update_datetime` 列），把物种、个体或评分的旧值改为新值；原值为空的行表示新增。
- **整表写入**：把表中的标签原样写入 XMP，例如标注员填好的表、从 Caracal 导出的表。空白单元格不改动文件。

## 输入

- **修改表**：标签获取以「XMP sidecar」为来源生成的表（`path` 列是 `.xmp` 文件），或整表写入用的表。
- **写入的字段**（整表写入）：物种、个体、评分、时间。时间默认不写入。

## 输出

- 直接修改表中列出的 XMP 文件。运行前会先检查，列出每个字段将改动多少个文件、哪些行有冲突。
- 每个被修改的 XMP 旁边保留一份备份（`<文件>.<时间>.backup`）。

## 注意

- 用 Excel / WPS 保存过的表，时间可能缺少秒数；写入时间前请先在表格软件里改好格式。
- 有冲突的行（同一个文件的几行写了不同的值）需要先在表里改好。
