# 物种名替换

按物种名录把表中的物种名换成另一种写法，例如英文名换成中文名或学名。

## 输入

- **要替换的表**：标签获取生成的 tags.csv 等。
- **物种名录**：每一列是一种写法的表（例如 taglist_maze.csv 的 `tag`、`tagCN` 列）。
- **从这一列**、**换成这一列**：物种名录中的两列。

## 输出

- `…_serval_output/serval_translate/`：替换后的表，原表不变。

## 注意

- 运行前会检查表中每个物种：不在物种名录里、名录里翻译为空、或在名录里重复出现时，会列出这些物种，补好名录后才能运行。
