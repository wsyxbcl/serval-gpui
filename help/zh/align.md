# 路径对齐

整理文件的目录结构：

- 提供**位点表**（deployments.csv）时，按位点把各位点的文件整理到统一的目录；
- 不提供时，把文件夹里的文件摊平到一个目录。

## 输入

- **项目或文件夹**：要整理的项目文件夹（按位点对齐）或普通文件夹（摊平）。
- **位点表**（可选）：deployments.csv，其中的 deploymentID 形如 `<位点>_<样区>`（可先用重命名统一文件夹名）。
- **文件类型**：媒体、图片、视频或 XMP。
- **移动而不是复制**、**保留第一层子文件夹（摊平时）**、**先预览，不复制**（默认开启）。

## 输出

- `…_serval_output/serval_align/`：整理后的文件。

## 注意

- 选择「移动」时原位置的文件会被移走。
- 先预览，确认无误后按「按此执行」。
