# 查看媒体

打开一张标签表，按物种和评分筛选，再交给其他工具查看和修改：资源管理器、Caracal，或把改好的表写回 XMP。

## 输入

- **标签表**：标签获取生成的 tags.csv、标注好的表，或从 Caracal 导出的表。
- **物种**、**评分**：勾选要看的物种，选择评分范围；下面会显示选中多少个文件。

## 三种用法

- **在资源管理器中查看所选**：在 `…_serval_output/serval_review/` 里为选中的媒体（连同 XMP）建立硬链接，并打开这个文件夹。缩略图、照片应用和播放器都可以直接使用，不会额外占用存储空间。
- **在 Caracal 中查看和编辑**：在浏览器中打开 Caracal，查看、评分、修改物种后导出 tags.csv。
- **应用表格到文件**：打开 XMP 更新（整表写入），把这张表写回 XMP。

## 注意

- 查看文件夹里的文件就是原文件：在这里编辑会改动原文件；删除只删除链接。
- 硬链接需要媒体和查看文件夹在同一个磁盘上。不能建立时，可以用 Caracal，或用媒体提取复制出来。
