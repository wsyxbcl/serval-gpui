# 媒体提取

按标签表筛选，把照片、视频连同 XMP 一起复制到新文件夹。

## 输入

- **标签表**：标签读取生成的 tags.csv。
- **选择要提取的记录**：勾选物种，选择评分范围；下面会显示文件数、记录数和大小。
- **保留的文件夹**：在路径条里点选要保留的最上层文件夹（例如位点）。选「只要文件」则不保留文件夹。
- **整理方式**：按物种分子文件夹；文件名加上标签（`物种__个体__原文件名`）。

## 输出

- `…_serval_output/serval_extract/<日期>_<物种>/`：复制出的媒体和 XMP。同样的选择再次运行会接着复制，已复制的文件会跳过。

## 注意

- 目标位置已有内容不同的文件时，会先询问：跳过、替换，或另存为新名称。
