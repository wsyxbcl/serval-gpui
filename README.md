Waxbill is the desktop app for [Serval](https://github.com/wsyxbcl/Serval). Waxbill 是 Serval 的图形界面。

## Build

```sh
cargo build --release
```

On Linux, install the development packages for fontconfig, freetype, Wayland, xkbcommon and xcb first (Debian /
Ubuntu: `libfontconfig1-dev libfreetype-dev libwayland-dev libxkbcommon-dev libxkbcommon-x11-dev libxcb1-dev
libx11-xcb-dev pkg-config cmake`).
