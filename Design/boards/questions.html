Questions become fields

Rules: spec/questions.md, spec/serval-protocol.md. Everything Serval used to ask while running is answered in the form before Run and passed as flags, except the two questions that depend on what the run finds: conflicts (in run-states) and identified species (③). Path levels are chosen on a real sample path read from the input; Serval's own guess is preselected.

按物种分子文件夹文件名加上标签
文件名格式：物种__个体__原文件名，多个值用 + 连接，例如 雪豹+岩羊__SL01__IMG_0001.JPG
就绪· 1,500 条记录
serval extract -f species -v 雪豹 --keep-dirs 2 --rename --progress json -o …/serval_extract …/tags_2024_spring.csv
复制命令 运行 Ctrl+Enter
--keep-dirs N counts folders upward from the file (0 = file only), matching how extract builds paths today.
